Kaggle Batch Writer

A personal automation tool used by its owner only. It saves output files produced by the owner's own Kaggle kernels (image generation batches) into the owner's Google Drive folder "kaggle-batch-output", so the results can be collected without manual downloads.

Privacy Policy

This app requests only the Google Drive "drive.file" scope: it can access solely the files and folders it creates itself. It does not read, modify, or delete any other files in the owner's Drive. No data is collected, stored on third-party servers, shared, or sold. The OAuth credential is stored in a private Kaggle dataset accessible only to the owner and is used only by the owner's own kernels to upload their outputs.
